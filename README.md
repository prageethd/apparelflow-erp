# ApparelFlow ERP

Production Batch Verification & Sewing Queue Gate

## Tech Stack

Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

Backend
- Node.js
- Express.js
- JWT

Database
- PostgreSQL
- Prisma

## Roles

- Cutting Supervisor
- Cutting Verifier
- Sewing Supervisor

## Development

Frontend:
npm run dev

Backend:
npm run dev

## Database

npx prisma migrate dev
npx prisma db seed
npx prisma studio
